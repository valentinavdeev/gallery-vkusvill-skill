# ВкусВилл: тестовый skill для Google AI Edge Gallery

Публичный поиск товаров и просмотр состава через официальный MCP `https://mcp.vkusvill.ru/mcp`. Локальная модель выбирает действие; запрос выполняется через JavaScript skill. Это **неофициальный эксперимент**, не продукт Google/ВкусВилла.

## Важное ограничение

**Работа на iPhone пока не подтверждена.** Прямой browser/WebView запрос может блокироваться CORS: при разработке OPTIONS сервера возвращал HTTP 401. Цель этой версии — проверить поведение непосредственно в Gallery, без прокси и отключения защиты. Ошибка подключения — допустимый результат теста, не признак отсутствия товаров.

## Добавить в Gallery

1. Откройте **Agent Skills**, выберите совместимую модель. Документация Gallery рекомендует Gemma 4 E4B для tools; это не гарантия скорости на любом iPhone.
2. **Skills → (+) → Load skill from URL**.
3. Вставьте URL **папки**, без `SKILL.md`:

```text
https://valentinavdeev.github.io/gallery-vkusvill-skill/
```

4. Включите только этот skill для первой проверки.
5. Напишите: **«Проверь подключение к ВкусВиллу»**.
6. Если подключение удалось: **«Найди три варианта овсяных хлопьев, сначала недорогие»**.
7. Затем: **«Покажи состав второго найденного товара»**.

Названия кнопок зависят от версии Gallery. Если модель не вызывает skill, попробуйте: «Используй vkusvill-public-search: вызови run_js, script name index.html, data {\"action\":\"ping\"}».

## Что прислать после теста

- модель iPhone, версия iOS и Gallery;
- выбранная модель;
- удалось ли импортировать skill;
- скрин результата и панели tool execution (без личных данных);
- при ошибке — код: NETWORK_OR_CORS, TIMEOUT, HTTP_401, VKUSVILL_ERROR и т. п.

`ping` проверяет handshake сервера, но не поиск. HTTP 200 тоже не гарантирует успех: сервер может вернуть application error внутри JSON.

## Границы

- Нет cookies, API keys, логина, истории заказов и персональных данных.
- Нет создания корзины, оплаты и других покупок.
- URL сервера фиксирован; разрешены только публичные поиск и детали.
- Запрос и ID товара отправляются ВкусВиллу. Инструмент не offline.
- Цены/состав — публичные данные. Наличие по адресу не проверяется.
- Состав при аллергии проверяйте по карточке и упаковке. Модель может неверно истолковать данные.
- Не передавайте сюда адрес, телефон и медицинские сведения.
- Установка по URL скачивает файлы с GitHub Pages. Отключить стандартную телеметрию самой Gallery этот skill не может.

Внешних JS-библиотек, CDN и proxy нет. Скрипт получает JSON-RPC, возвращает короткие карточки и диагностические ошибки. Не используйте `mode:no-cors`: он не позволит прочитать ответ.

## Проверки разработки

```sh
node --test tests/skill.test.mjs
node --check scripts/index.js
```

Unit-тесты используют mocks. Они не доказывают работоспособность WKWebView или качество Gemma. curl/Node могут успешно обращаться к серверу там, где browser fetch блокируется.
